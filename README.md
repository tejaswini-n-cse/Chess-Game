# ♟️ Chess Game App

A simple and interactive **Two-Player Chess Game Application** developed using **JavaScript, HTML, and CSS**. This project allows two players to play chess in a browser environment with an intuitive interface and basic chess game logic.

The main objective of this project is to implement game rules, user interactions, and JavaScript-based logic while improving frontend development skills.

---

## 📌 Project Overview

The **Chess Game App** is a beginner-friendly web-based chess application where two players can play against each other on the same device.

The application provides an interactive chess board, allows players to move pieces according to chess rules, and manages player turns throughout the game.

---

## ✨ Features

✅ Two-player chess gameplay  
✅ Interactive chess board interface  
✅ Turn-based player movement  
✅ Chess piece movement handling  
✅ User-friendly design  
✅ Real-time game interaction  
✅ Browser-based application (No installation required)

## 🎮 How to Play

1. Open the application in a web browser.
2. Player 1 starts the game with White pieces.
3. Player 2 plays with Black pieces.
4. Click on a chess piece and select the desired position.
5. Continue playing until the game reaches a winning condition.
